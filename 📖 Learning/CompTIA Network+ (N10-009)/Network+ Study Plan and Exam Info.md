---

## Exam snapshot

| Detail | Info |
|---|---|
| Exam code | N10-009 (V9) |
| Level | Early-career networking |
| Format | Multiple-choice/multiple-response, performance-based |
| Length | 90 minutes, max 90 questions |
| Passing score | 720 / 900 (commonly cited — verify current figure) |
| Recommended experience | CompTIA A+, plus 9-12 months in a junior network admin/support role |
| Validity | 3 years |

> [!warning] Verify before booking
> Confirm current format/pricing/passing score on the [official CompTIA Network+ exam page](https://www.comptia.org/certifications/network) — CompTIA updates these periodically, and the passing score specifically wasn't listed in this exam's own objectives document.

## ✅ Study checklist

### Phase 1 — Networking Concepts (23%)
- [ ] Read all 3 Networking Concepts notes fully
- [ ] Memorize the OSI model, both directions
- [ ] Memorize the full Network+ port list — it's longer than A+'s
- [ ] Practice subnetting calculations until they're fast, not just correct
- [ ] Drill [[Identifying the OSI Layer for a Network Function]]
- [ ] Drill [[Choosing the Right Networking Appliance]]
- [ ] Drill [[Choosing the Right Cloud Service and Deployment Model]]
- [ ] Drill [[Identifying a Protocol by Port Number]]
- [ ] Drill [[Choosing the Right Transmission Media and Connector]]
- [ ] Drill [[Choosing the Right Network Topology]]
- [ ] Drill [[Applying IPv4 Addressing and Subnetting]]

### Phase 2 — Network Implementation (20%)
- [ ] Read both Network Implementation notes fully
- [ ] Know route selection as two separate mechanisms: longest prefix match, then AD/metric
- [ ] Know PSK vs. Enterprise wireless authentication cold
- [ ] Drill [[Choosing a Routing Protocol and Understanding Route Selection]]
- [ ] Drill [[Configuring Switching Technologies for a Scenario]]
- [ ] Drill [[Configuring Wireless Devices for a Scenario]]
- [ ] Drill [[Planning a Physical Network Installation]]

### Phase 3 — Network Operations (19%)
- [ ] Read all 3 Network Operations notes fully
- [ ] Know RPO vs. RTO cold, and cold/warm/hot site trade-offs
- [ ] Know every DNS record type and what it resolves
- [ ] Know in-band vs. out-of-band management
- [ ] Drill [[Using Network Monitoring Technologies for a Scenario]]
- [ ] Drill [[Choosing the Right Disaster Recovery Approach]]
- [ ] Drill [[Identifying DNS Record Types and Implementing IP Services]]
- [ ] Drill [[Choosing the Right Network Access and Management Method]]

### Phase 4 — Network Security (14%)
- [ ] Read both Network Security notes fully
- [ ] Know AAA and the four identity protocols (RADIUS, TACACS+, LDAP, SAML)
- [ ] Know Layer 2 attacks (VLAN hopping, MAC flooding, ARP poisoning) cold — heavily tested
- [ ] Drill [[Identifying Network Attack Types]]
- [ ] Drill [[Applying Network Security Features for a Scenario]]
- [ ] Drill [[Choosing the Right Authentication Method]]

### Phase 5 — Network Troubleshooting (24% — the biggest domain)
- [ ] Read [[Network Troubleshooting Methodology and Overview]] fully
- [ ] Recite the 7-step troubleshooting methodology from memory, in order
- [ ] Know top-down, bottom-up, and divide-and-conquer as OSI-based approaches
- [ ] Drill [[Troubleshooting Cabling and Physical Interface Issues]]
- [ ] Drill [[Troubleshooting Network Service Issues]]
- [ ] Drill [[Troubleshooting Network Performance Issues]]
- [ ] Drill [[Choosing the Right Tool or Protocol to Solve a Networking Issue]]

### Phase 6 — Exam readiness
- [ ] Take a full practice test, review every wrong answer against the relevant Concept note
- [ ] Read [[Network+ Cheat Sheet]] end-to-end, self-test each row
- [ ] Confirm current exam price/format/passing score on the official page
- [ ] Schedule the exam

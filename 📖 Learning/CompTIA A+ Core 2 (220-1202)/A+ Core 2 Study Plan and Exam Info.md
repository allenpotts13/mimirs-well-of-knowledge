## ✅ Study checklist

### Phase 1 — Operating Systems (28%)
- [ ] Read all 4 Operating Systems concept notes fully
- [ ] Know every Windows edition's feature ceiling (domain join, BitLocker, RDP host)
- [ ] Memorize the `.msc`/`.exe` tool list cold
- [ ] Memorize the command-line tool list — especially `chkdsk` vs `sfc`
- [ ] Know macOS and Linux tool/command equivalents to Windows tasks
- [ ] Drill [[Choosing the Right Windows Administrative Tool]]
- [ ] Drill [[Choosing the Right Windows Command-Line Tool]]
- [ ] Drill [[Configuring Windows Settings for a Scenario]]
- [ ] Drill [[Configuring Windows Networking Features]]
- [ ] Drill [[Choosing Between Windows, macOS, and Linux Tools]]

### Phase 2 — Security (28%)
- [ ] Read all 3 Security concept notes fully
- [ ] Memorize all malware types and their signature behavior
- [ ] Memorize the 10-step SOHO malware removal procedure, in order
- [ ] Know the wireless security ranking (WPA3 > WPA2 > WPA/TKIP > WEP)
- [ ] Know NTFS vs. share permissions and which wins when combined
- [ ] Drill [[Identifying Malware Types and Removal Steps]]
- [ ] Drill [[Spotting Social Engineering Attacks]]
- [ ] Drill [[Choosing the Right Wireless Security Protocol]]
- [ ] Drill [[Applying Workstation Hardening Techniques]]
- [ ] Drill [[Securing Mobile Devices]]

### Phase 3 — Software Troubleshooting (23%)
- [ ] Read [[Software Troubleshooting]] fully
- [ ] Practice distinguishing security vs. non-security mobile symptoms
- [ ] Drill [[Troubleshooting Common Windows OS Issues]]
- [ ] Drill [[Troubleshooting Mobile OS and Application Issues]]
- [ ] Drill [[Troubleshooting Mobile OS and Application Security Issues]]
- [ ] Drill [[Troubleshooting Common PC Security Issues]]

### Phase 4 — Operational Procedures (21%)
- [ ] Read both Operational Procedures concept notes fully
- [ ] Know the difference between standard/normal/emergency change
- [ ] Know all backup types and the 3-2-1 rule cold
- [ ] Know which safety procedures protect components (ESD) vs. people (electrical/personal safety)
- [ ] Review professionalism scenarios — pick the patient, communicative answer every time
- [ ] Drill [[Applying Change Management Procedures]]
- [ ] Drill [[Choosing the Right Backup and Recovery Method]]
- [ ] Drill [[Applying Safety Procedures in the Workplace]]
- [ ] Drill [[Using Proper Communication Techniques and Professionalism]]
- [ ] Drill [[Choosing the Right Remote Access Technology]]

### Phase 5 — Exam readiness
- [ ] Take a full practice test, review every wrong answer against the relevant Concept note
- [ ] Read [[A+ Core 2 Cheat Sheet]] end-to-end, self-test each row
- [ ] Confirm current exam price/format on the official page
- [ ] Schedule the exam (after Core 1, if not already passed)

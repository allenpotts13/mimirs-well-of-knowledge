# <span class="rune">ᛗ</span> A+ Core 2: CompTIA A+ (220-1202)

> "Core 1 is the machine. Core 2 is everything running on it — and everything trying to get in."

---

## 🎯 What is A+ Core 2?

The second of two exams required for CompTIA A+ certification. Core 2 (220-1202) covers the software side: operating systems (Windows, macOS, Linux), security, software troubleshooting, and operational procedures. [[A+ Core 1 Codex|Core 1 (220-1201)]] covers the hardware and connectivity side.

| Detail | Info |
|---|---|
| Level | Entry-level IT support |
| Format | Multiple choice/multiple answer, drag-and-drop, performance-based |
| Length | 90 minutes, max 90 questions |
| Passing score | 700 / 900 |
| Prerequisites | None |
| Companion exam | Core 1 (220-1201) — both required for A+ certification |

> [!warning] Confirm before booking
> CompTIA updates exam format, pricing, and skills outlines periodically — double-check current details on the [official A+ exam page](https://www.comptia.org/certifications/a) before scheduling.

## 📚 Concepts

The four domains measured on the exam:

- [[Operating System Types and Installation]] — OS types, filesystems, install/upgrade, Windows editions *(part of 28%)*
- [[Windows Administration Tools and Command Line]] — GUI tools and CLI commands *(part of 28%)*
- [[Windows Settings and Networking Configuration]] — Settings/Control Panel, client networking *(part of 28%)*
- [[macOS, Linux, and Application Management]] — macOS/Linux tools, app installation, cloud productivity *(part of 28%)*
- [[Security Fundamentals, Malware, and Social Engineering]] — physical/logical security, malware, social engineering *(part of 28%)*
- [[Windows and Network Security Configuration]] — Windows security settings, wireless protocols, SOHO/browser security *(part of 28%)*
- [[Workstation Hardening, Mobile Security, and Data Destruction]] — hardening, malware removal, mobile security, disposal *(part of 28%)*
- [[Software Troubleshooting]] — Windows, mobile OS/app, and PC security symptom diagnosis *(23%)*
- [[Documentation, Change Management, and Backup]] — ticketing, asset management, change control, backups *(part of 21%)*
- [[Safety, Compliance, Professionalism, and Emerging Technology]] — safety, privacy/licensing, professionalism, scripting, remote access, AI *(part of 21%)*

## Exam snapshot

| Detail | Info |
|---|---|
| Exam code | SY0-701 (V7) |
| Level | Early-career security |
| Format | Multiple-choice/multiple-response, performance-based |
| Length | 90 minutes, max 90 questions |
| Passing score | 750 / 900 (commonly cited — verify current figure) |
| Recommended experience | ~2 years in IT administration with a security focus |
| Validity | 3 years |

> [!warning] Verify before booking
> Confirm current format/pricing/passing score on the [official CompTIA Security+ exam page](https://www.comptia.org/certifications/security) — CompTIA updates these periodically, and the passing score specifically wasn't listed in this exam's own objectives document.

## ✅ Study checklist

### Phase 1 — General Security Concepts (12%)
- [ ] Read both notes fully
- [ ] Know control category vs. type as two independent axes
- [ ] Understand Zero Trust's control plane vs. data plane
- [ ] Know symmetric vs. asymmetric, and hashing vs. encryption cold
- [ ] Drill [[Identifying the Right Security Control Type]]
- [ ] Drill [[Applying Zero Trust and AAA Concepts]]
- [ ] Drill [[Evaluating Change Management Impact on Security]]
- [ ] Drill [[Choosing the Right Cryptographic Solution]]

### Phase 2 — Threats, Vulnerabilities, and Mitigations (22%)
- [ ] Read all 3 notes fully — this domain has the densest sub-bullet lists on the exam
- [ ] Memorize threat actor types and their typical motivations
- [ ] Memorize all malware types by signature behavior
- [ ] Know password spraying vs. brute force, and amplified vs. reflected DDoS cold
- [ ] Drill [[Identifying Threat Actor Types and Motivations]]
- [ ] Drill [[Identifying Threat Vectors and Attack Surfaces]]
- [ ] Drill [[Classifying a Vulnerability by Type]]
- [ ] Drill [[Identifying Malware and Physical Attack Types]]
- [ ] Drill [[Identifying Network, Application, and Password Attacks]]
- [ ] Drill [[Choosing the Right Mitigation Technique]]

### Phase 3 — Security Architecture (18%)
- [ ] Read both notes fully
- [ ] Know fail-open vs. fail-closed and inline vs. tap/monitor
- [ ] Know data states (at rest/in transit/in use) and site tiers (cold/warm/hot)
- [ ] Drill [[Choosing the Right Architecture Model]]
- [ ] Drill [[Selecting Network Security Infrastructure and Appliances]]
- [ ] Drill [[Applying Data Protection Strategies]]
- [ ] Drill [[Choosing the Right High-Availability and Recovery Strategy]]

### Phase 4 — Security Operations (28% — the biggest domain)
- [ ] Read all 4 notes fully
- [ ] Know BYOD/COPE/CYOD cold
- [ ] Know CVE vs. CVSS, false positive vs. false negative
- [ ] Know SPF/DKIM/DMARC and every access control model (DAC/MAC/RBAC/rule-based/ABAC)
- [ ] Recite the 7-step incident response process from memory, in order
- [ ] Drill [[Hardening Devices and Systems for a Scenario]]
- [ ] Drill [[Applying Asset Management Practices]]
- [ ] Drill [[Understanding Vulnerability Management Activities]]
- [ ] Drill [[Choosing the Right Security Monitoring Tool]]
- [ ] Drill [[Modifying Enterprise Capabilities to Enhance Security]]
- [ ] Drill [[Implementing Identity and Access Management]]
- [ ] Drill [[Applying Automation and Orchestration Concepts]]
- [ ] Drill [[Applying Incident Response Activities]]
- [ ] Drill [[Using Data Sources to Support an Investigation]]

### Phase 5 — Security Program Management and Oversight (20%)
- [ ] Read all 3 notes fully
- [ ] Know the governance document hierarchy (guideline/policy/procedure/standard)
- [ ] Memorize SLE × ARO = ALE and be able to calculate it under pressure
- [ ] Know all third-party agreement types (MSA/SOW/NDA/SLA/MOU/MOA/BPA)
- [ ] Drill [[Understanding Security Governance Elements]]
- [ ] Drill [[Applying Risk Management Concepts]]
- [ ] Drill [[Managing Third-Party Risk]]
- [ ] Drill [[Understanding Security Compliance Elements]]
- [ ] Drill [[Choosing the Right Audit or Assessment Type]]
- [ ] Drill [[Implementing Security Awareness Practices]]

### Phase 6 — Exam readiness
- [ ] Take a full practice test, review every wrong answer against the relevant Concept note
- [ ] Read [[Security+ Cheat Sheet]] end-to-end, self-test each row
- [ ] Confirm current exam price/format/passing score on the official page
- [ ] Schedule the exam

# <span class="rune">ᚲ</span> Implementing Security Awareness Practices

> *A single annual training video is not a security awareness program — it's one input into an ongoing cycle.*

---

## 🎯 Problem

A scenario describes an employee behavior or a security awareness initiative. Identify the correct practice or classification.

---

## 🤔 Mental Model

| Signal in the scenario | Answer |
|---|---|
| "employees receive simulated phishing emails to test recognition" | Phishing campaign |
| "an employee reports a suspicious email for review" | Reporting and monitoring |
| "a user's behavior is unusual but clearly not malicious intent" | Anomalous — unintentional |
| "a user's behavior is unusual and potentially risky but not clearly malicious" | Anomalous — risky |
| "a user's behavior is surprising and out of pattern generally" | Anomalous — unexpected |
| "training covers how to handle sensitive conversations discreetly" | Situational awareness / operational security |
| "policy addresses remote and hybrid work-specific risks" | Hybrid/remote work environment guidance |
| "training addresses proper handling of USB drives and cables" | Removable media and cables guidance |
| "the awareness program itself is being built and rolled out" | Development and execution |

---

## 🧠 Why This Pattern Works

Security awareness isn't one activity — it's a cycle covering phishing simulation, behavior recognition, ongoing training/guidance, and a reporting loop that feeds back into the program's development. Anomalous behavior recognition specifically has three flavors (risky, unexpected, unintentional) that describe *why* something looks off, distinct from whether it's confirmed malicious — that judgment call comes later, after investigation.

---

## 🚨 Common Mistakes

- Treating a single training session as a complete security awareness program rather than one piece of an ongoing cycle
- Confusing "risky" (a choice that increases exposure) with "unintentional" (an honest mistake) behavior — they call for different responses
- Overlooking hybrid/remote work as its own specific awareness topic rather than folding it into generic guidance
- Forgetting the reporting/monitoring loop is part of the program — awareness efforts should feed back into what gets taught next

---

## 💡 Wisdom from Mímir

Security awareness questions test the cycle, not a single event: train, simulate (phishing), recognize (anomalies), report, and repeat. Any answer treating it as a one-time task is probably wrong.

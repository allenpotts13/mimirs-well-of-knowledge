# <span class="rune">ᛃ</span> A+ Core 1 Study Plan and Exam Info

---

## Exam snapshot

| Detail | Info |
|---|---|
| Exam code | 220-1201 (V15) |
| Level | Entry-level IT support |
| Format | Multiple-choice/multiple-response, drag-and-drop, performance-based |
| Length | 90 minutes, max 90 questions |
| Passing score | 675 / 900 |
| Prerequisites | None (CompTIA recommends none, but hands-on exposure helps) |
| Companion exam | Must also pass [[A+ Core 2 Codex|Core 2 (220-1202)]] for full A+ certification |
| Validity | 3 years |

> [!warning] Verify before booking
> Confirm current format/pricing on the [official CompTIA A+ exam page](https://www.comptia.org/certifications/a) — CompTIA updates these periodically.

## ✅ Study checklist

### Phase 1 — Mobile Devices (13%)
- [ ] Read [[Mobile Devices]] fully
- [ ] Know every field-replaceable mobile component by name
- [ ] Distinguish connection methods from accessories
- [ ] Drill [[Choosing the Right Mobile Device Connectivity Accessory]]
- [ ] Drill [[Configuring Mobile Device Network Connectivity]]

### Phase 2 — Networking (23%)
- [ ] Read [[Networking Fundamentals]] fully
- [ ] Memorize the common port list cold — no looking it up
- [ ] Explain TCP vs. UDP and name 3 examples of each
- [ ] Read [[Networking Hardware and SOHO Setup]] fully
- [ ] Recognize APIPA instantly and know what it means
- [ ] Drill [[TCP vs UDP - Choosing the Right Transport Protocol]]
- [ ] Drill [[Identifying Wireless Networking Standards and Frequencies]]
- [ ] Drill [[Choosing the Right Networking Hardware Device]]
- [ ] Drill [[Configuring a Basic SOHO Network]]
- [ ] Drill [[Comparing Internet Connection Types]]

### Phase 3 — Hardware (25%)
- [ ] Read [[Core Hardware Components]] fully
- [ ] Know display panel types (IPS/TN/VA) and their trade-offs
- [ ] Know every RAID level's fault tolerance and usable capacity
- [ ] Read [[System Assembly, Power, and Printers]] fully
- [ ] Know motherboard form factors and BIOS/UEFI security settings (TPM, Secure Boot)
- [ ] Know printer maintenance steps by printer technology
- [ ] Drill [[Choosing the Right RAM for a Build]]
- [ ] Drill [[Choosing the Right Storage Device]]
- [ ] Drill [[Selecting the Right Power Supply for a Build]]
- [ ] Drill [[Choosing a Multifunction Printer Connection Type]]

### Phase 4 — Virtualization and Cloud Computing (11%)
- [ ] Read [[Virtualization and Cloud Computing]] fully
- [ ] Explain Type 1 vs. Type 2 hypervisors without notes
- [ ] Explain IaaS/PaaS/SaaS and cloud deployment models
- [ ] Drill [[Choosing a Hypervisor Type]]
- [ ] Drill [[Matching a Scenario to a Cloud Characteristic]]

### Phase 5 — Hardware and Network Troubleshooting (28% — the biggest domain)
- [ ] Read [[Hardware and Network Troubleshooting]] fully
- [ ] Recite the 6-step troubleshooting methodology from memory, in order
- [ ] Drill [[Troubleshooting Motherboard, RAM, CPU, and Power Issues]]
- [ ] Drill [[Troubleshooting Drive and RAID Issues]]
- [ ] Drill [[Troubleshooting Video, Projector, and Display Issues]]
- [ ] Drill [[Troubleshooting Common Mobile Device Issues]]
- [ ] Drill [[Troubleshooting Network Issues]]
- [ ] Drill [[Troubleshooting Printer Issues]]

### Phase 6 — Exam readiness
- [ ] Take a full practice test, review every wrong answer against the relevant Concept note
- [ ] Read [[A+ Core 1 Cheat Sheet]] end-to-end, self-test each row
- [ ] Confirm current exam price/format on the official page
- [ ] Schedule the exam

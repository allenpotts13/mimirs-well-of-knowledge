# <span class="rune">ᚢ</span> A+ Core 1: CompTIA A+ (220-1201)

> "Every device on this exam eventually fails in a predictable way — the job is knowing which predictable way."

---

## 🎯 What is A+ Core 1?

The first of two exams required for CompTIA A+ certification — the industry-standard entry point into IT support. Core 1 (220-1201) covers the hardware and connectivity side: mobile devices, networking, hardware components, virtualization/cloud basics, and troubleshooting methodology. [[A+ Core 2 Codex|Core 2 (220-1202)]] covers the software/OS, security, and operational side.

| Detail | Info |
|---|---|
| Level | Entry-level IT support |
| Format | Multiple choice/multiple answer, drag-and-drop, performance-based |
| Length | 90 minutes, max 90 questions |
| Passing score | 675 / 900 |
| Prerequisites | None |
| Companion exam | Core 2 (220-1202) — both required for A+ certification |

> [!warning] Confirm before booking
> CompTIA updates exam format, pricing, and skills outlines periodically — double-check current details on the [official A+ exam page](https://www.comptia.org/certifications/a) before scheduling.

## 📚 Concepts

The five domains measured on the exam:

- [[Mobile Devices]] — hardware, accessories, network connectivity *(13%)*
- [[Networking Fundamentals]] — ports, protocols, wireless, network services *(part of 23%)*
- [[Networking Hardware and SOHO Setup]] — devices, IP addressing, connection types, tools *(part of 23%)*
- [[Core Hardware Components]] — displays, cables, RAM, storage *(part of 25%)*
- [[System Assembly, Power, and Printers]] — motherboards, CPUs, power supplies, printers *(part of 25%)*
- [[Virtualization and Cloud Computing]] — hypervisors, containers, cloud models *(11%)*
- [[Hardware and Network Troubleshooting]] — the CompTIA troubleshooting methodology *(28% — the largest domain)*

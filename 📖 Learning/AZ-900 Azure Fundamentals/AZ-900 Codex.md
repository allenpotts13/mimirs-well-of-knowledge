# <span class="rune">ᚱ</span> AZ-900: Microsoft Certified Azure Fundamentals

> "Before you can reason about any one Azure service, you need the shape of the whole cloud in your head."

---

## 🎯 What is AZ-900?

A Microsoft **Fundamentals-level** certification validating a foundational understanding of cloud concepts and how Microsoft Azure implements them — compute, networking, storage, identity, cost, and governance, at a conceptual (not hands-on) level. No prior experience required. Doesn't expire.

| Detail | Info |
|---|---|
| Level | Fundamentals |
| Format | Multiple choice / multiple answer, drag-and-drop, case studies |
| Length | ~45–60 min, ~40–60 questions |
| Passing score | 700 / 1000 |
| Prerequisites | None |

> [!warning] Confirm before booking
> Microsoft updates exam format, pricing, and skills outlines periodically — double-check current details on the [official exam page](https://learn.microsoft.com/en-us/credentials/certifications/exams/az-900/) before scheduling.

> [!tip] How this differs from DP-900
> [[DP-900 Codex|DP-900]] is Azure's *data* fundamentals cert (databases, analytics, Power BI). AZ-900 is the *general* Azure fundamentals cert — cloud concepts, core infrastructure, identity, governance, and cost. AZ-900 is the broader/shallower of the two and is usually taken first.

---

## 📚 Concepts

The three domains measured on the exam:

- [[Cloud Concepts]] — cloud models, service models, cloud economics, key benefits *(~25–30% of exam)*
- [[Core Azure Architecture and Services]] — regions, resource hierarchy, compute, networking, storage *(~35–40%)*
- [[Identity, Access, and Security]] — Entra ID, RBAC, Zero Trust, defense in depth *(part of architecture & services domain, split out for depth)*
- [[Azure Management and Governance]] — cost tools, governance tools, monitoring, deployment tools *(~30–35%)*

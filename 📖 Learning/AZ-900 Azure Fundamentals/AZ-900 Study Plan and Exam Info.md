## ✅ Study checklist

### Phase 1 — Cloud concepts
- [ ] Read [[Cloud Concepts]] fully
- [ ] Explain public/private/hybrid/multi-cloud from memory
- [ ] Explain IaaS vs PaaS vs SaaS without notes
- [ ] Explain CapEx vs OpEx and why cloud is OpEx
- [ ] Drill [[Public vs Private vs Hybrid vs Multi-Cloud]]
- [ ] Drill [[IaaS vs PaaS vs SaaS - Spotting the Service Model]]
- [ ] Drill [[CapEx vs OpEx and the Economics of Cloud]]

### Phase 2 — Core architecture and services
- [ ] Read [[Core Azure Architecture and Services]] fully
- [ ] Draw the region → AZ → resource hierarchy from memory
- [ ] Know all 7 core compute services and when each fits
- [ ] Know VPN Gateway vs ExpressRoute, Load Balancer vs Application Gateway
- [ ] Drill [[Choosing the Right Azure Compute Service]]
- [ ] Drill [[Regions vs Availability Zones vs Region Pairs]]

### Phase 3 — Identity, access, and security
- [ ] Read [[Identity, Access, and Security]] fully
- [ ] Explain authentication vs authorization
- [ ] Know Azure RBAC scope inheritance
- [ ] Explain Zero Trust and defense in depth in your own words
- [ ] Drill [[Choosing an Identity and Access Tool]]

### Phase 4 — Management and governance
- [ ] Read [[Azure Management and Governance]] fully
- [ ] Know the difference between Policy, RBAC, and resource locks cold
- [ ] Know Pricing calculator vs TCO calculator vs Cost Management
- [ ] Know Azure Advisor vs Azure Service Health
- [ ] Drill [[Azure RBAC vs Azure Policy vs Resource Locks]]
- [ ] Drill [[Picking the Right Cost Management Tool]]

### Phase 5 — Exam readiness
- [ ] Complete the [Microsoft Learn AZ-900 path](https://learn.microsoft.com/en-us/training/paths/azure-fundamentals-describe-cloud-concepts/)
- [ ] Take a full practice test, review every wrong answer
- [ ] Read [[AZ-900 Cheat Sheet]] end-to-end, self-test each row
- [ ] Schedule the exam

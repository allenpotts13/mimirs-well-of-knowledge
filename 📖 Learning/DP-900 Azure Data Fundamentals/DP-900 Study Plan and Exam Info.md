## Exam snapshot

| Detail | Info |
|---|---|

| Format | Multiple choice / multiple answer, drag-and-drop, case studies |

## ✅ Study checklist

### Phase 1 — Foundations
- [ ] Read [[Core Data Concepts]] fully
- [ ] Explain structured vs. semi-structured vs. unstructured from memory
- [ ] Explain OLTP vs. OLAP without notes
- [ ] Know DBA vs. data engineer vs. data analyst vs. data scientist

### Phase 2 — Relational
- [ ] Read [[Relational Data on Azure]] fully
- [ ] Drill [[Choosing Between Azure SQL Database, Managed Instance, and SQL Server on a VM]]
- [ ] Know DTU vs. vCore
- [ ] Refresh joins/normalization via [[SQL Codex]] if rusty

### Phase 3 — Non-relational
- [ ] Read [[Non-Relational Data on Azure]] fully
- [ ] Drill [[Choosing the Right Cosmos DB API]]
- [ ] Drill [[Picking a Blob Storage Access Tier]]
- [ ] Know all 5 Cosmos DB consistency levels in order

### Phase 4 — Analytics
- [ ] Read [[Analytics Workloads on Azure]] fully
- [ ] Draw the modern data warehouse pipeline from memory
- [ ] Drill [[Data Factory vs Stream Analytics vs Synapse]]
- [ ] Drill [[Star Schema - Fact Tables vs Dimension Tables]]
- [ ] Drill [[Power BI Desktop vs Service vs Mobile (DP-900)]]

### Phase 5 — Exam readiness
- [ ] Complete the [Microsoft Learn DP-900 path](https://learn.microsoft.com/en-us/training/paths/azure-data-fundamentals-explore-core-data-concepts/)
- [ ] Take a full practice test, review every wrong answer
- [ ] Read [[DP-900 Cheat Sheet]] end-to-end, self-test each row
- [ ] Schedule the exam

# ☁️ DP-900: Azure Data Fundamentals

> "Fundamentals aren't the easy part — they're the part everything else stands on."

---

## 🎯 What is DP-900?

A Microsoft **Fundamentals-level** certification validating baseline knowledge of core data concepts and how they map to Microsoft Azure data services. No prior Azure experience required. Doesn't expire.

| Detail | Info |
|---|---|
| Level | Fundamentals |
| Format | Multiple choice / multiple answer, drag-and-drop, case studies |
| Length | ~45–60 min, ~40–60 questions |
| Passing score | 700 / 1000 |
| Prerequisites | None |

> [!warning] Confirm before booking
> Microsoft updates exam format, pricing, and skills outlines periodically — double-check current details on the [official exam page](https://learn.microsoft.com/en-us/credentials/certifications/exams/dp-900/) before scheduling.

## 📚 Concepts

The four domains measured on the exam. Read these in order — each builds vocabulary the next one assumes.

- [[Core Data Concepts]] — data types, OLTP vs OLAP, data roles *(~25–30% of exam)*
- [[Relational Data on Azure]] — RDBMS theory + Azure SQL family *(~20–25%)*
- [[Non-Relational Data on Azure]] — NoSQL models, Cosmos DB, Azure Storage *(~15–20%)*
- [[Analytics Workloads on Azure]] — the modern data warehouse pipeline, Synapse, Power BI *(~25–30%)*

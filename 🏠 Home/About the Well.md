# About the Well

> *"Wisdom is earned through experience. Knowledge is preserved through discipline."*

Welcome to **Mímir's Well**.

This vault is more than a collection of notes. It is a living knowledge system designed to capture lessons, solutions, ideas, and experience accumulated throughout a career in technology.

Every note added to Mímir should answer a question, solve a problem, or preserve knowledge that would otherwise need to be learned again.

The purpose is simple:

> [!quote]
> **Never solve the same problem twice.**

---
# 📖 Philosophy

Information is everywhere.

Wisdom is rare.

Mímir is not a repository for copied documentation.

It is a place to preserve understanding.

Every note should answer:

- What is it?
- Why does it matter?
- When should I use it?
- What lesson did I learn?

# 📜 Core Principles

> [!tip]
> ## One Note = One Idea
>
> Every note should focus on a single concept.

> [!note]
> ## Link Knowledge
>
> Do not duplicate information.
> Connect it.

> [!important]
> ## Templates First 
 >Every note begins with the appropriate template.
>  Consistency makes knowledge easier to navigate, maintain, and expand.

> [!warning] 
>  ## Experience Matters  
>  Record more than facts. 
>  Capture decisions, mistakes, lessons learned, and the reasoning behind solutions.
>  Information explains *what*. 
>  Experience explains *why*.

> [!success] 
> ## Future You Comes First 
>  Every note should save time for your future self. 
>  If a note helps you avoid solving the same problem twice, it has fulfilled its purpose.

# 🧭 Navigation Philosophy

Knowledge in Mímir is organized through Codices.

Each Codex serves as the gateway to a specific domain of knowledge.

Every concept, project, troubleshooting guide, or code snippet should belong to a Codex and connect to related knowledge whenever possible.

The goal is not simply to store information.

The goal is to build an interconnected web of understanding.

---
# ⚖ The Oath of Mímir

Every note added to this vault should make tomorrow easier than today.

Knowledge without organization is forgotten.

Organization without understanding is empty.

Therefore, let every note strive to:

- Build understanding.
- Preserve wisdom.
- Share experience.
- Never solve the same problem twice.

| Elements   | Purpose                                                  | Example HTML                                                                                                                                                      |
| ---------- | -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| h1, h2, h3 | Headers. h1 is largest                                   | ```html<h2>Puppies are cute</h2>```                                                                                                                               |
| p          | Paragraph                                                | ```html<p>Humans seem designed to see puppies as cute.</p>```                                                                                                     |
| img        | Image                                                    | ```html<img src="https://resources.zybooks.com/WebProgramming/ducativ1.jpg" alt="Bike photo">```<br><br>Note: src is the image's URL, and alt describes the image |
| a          | Link                                                     | ```html<a href="https://www.wikipedia.org/">Click Here</a>```                                                                                                     |
| em, strong | Emphasis(italic), strong emphasis (bold)                 | ```html"When in <strong>doubt</strong>, tell the <em>truth</em>" -Mark Twain.```                                                                                  |
| cite       | denotes a title                                          | ```html<cite>Spaceballs</cite>```                                                                                                                                 |
| mark       | denotes important content, highlighted yellow by default | ```html<mark>Highlight</mark>```                                                                                                                                  |
| b          | indicates text that needs attention                      | ```html<p>Mix the <b>flour</b> and <b>oil</b> together.```                                                                                                        |
| i          | Text of an alternate voice or word from another language | ```html<i>italic</i>```                                                                                                                                           |
| u          | Text that is rendered differently from normal text       | ```html<u>underline</u>```                                                                                                                                        |
| del        | deleted text                                             | ```html<del>deleted text</del>```                                                                                                                                 |
